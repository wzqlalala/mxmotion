# 动画、曲线与力元验证项目

这两个项目都内嵌精确几何，可通过“文件 → 打开”加载，也可作为 `MxMotion` 的命令行参数。打开后重新求解，即可检查保存的曲线配置与实际动画。

| 项目 | 验证内容 |
| --- | --- |
| [rigid_results.mxmotion](rigid_results.mxmotion) | 偏置斜轴旋转、世界位置与位移增量、三条曲线及动画联动 |
| [native-forces.mxmotion](native-forces.mxmotion) | 原生模型、止挡、只拉绳索、体点弹簧、四类输出与动画 |

## 刚体动画与曲线

`rigid_results.mxmotion` 是带内嵌几何的刚体项目，可通过“文件 → 打开”加载，也可作为 `MxMotion` 的命令行参数。该项目由真实 MotionEngine 回归算例生成，包含偏置斜轴旋转体和按方案保存的曲线配置。

### 操作

1. 打开 `rigid_results.mxmotion`。
2. 在模型树中右键“偏置旋转”，选择“求解”。求解完成后，再点击其下的“运动曲线”。
3. 默认显示蓝色的“旋转副相对转角”和橙色的“质心世界位置 X”。绿色的“质心位移增量 X”默认隐藏，可以在参数栏的曲线列表中勾选。
4. 点击方案下的“动画”。拖动时间轴，或点击曲线中的某一时刻，检查几何姿态、帧索引和时间标记是否同步。动画参数中两个曲线联动开关可以单独关闭。
5. 暂停保持当前姿态；停止回第一帧。关闭动画或切回参数页时，几何恢复初始建模位置。

参数栏和模型树较矮时可纵向滚动，也可以拖动停靠分隔条扩大上方区域。偏置旋转会使模型离开初始视图中心，可在视口中缩小视图观察整个运动范围。

### 应看到什么

| 设置或结果 | 值 |
| --- | --- |
| 长方体尺寸 | 120 × 80 × 40 mm |
| 初始质心 | (60, 40, 20) mm |
| 旋转轴原点 | (17, −13, 11) mm |
| 旋转轴方向 | (2, −3, 6)，由后端归一化 |
| 恒定角速度 | 105 °/s |
| 结束时间 / 标称步长 | 2.003 s / 0.005 s |
| 实际采样 | 402 帧，最后一步为 0.003 s |
| 最终关节相对转角 | 210.315°，随时间线性增长 |
| 质心 X 初始值 | 世界位置为 60 mm，位移增量为 0 mm |

世界位置和位移增量相差初始位置，不能混为同一个量。关节相对转角与任意轴姿态的欧拉角分量也不是同一个量。图例给出每条曲线的单位；需要单独查看尺度时，可隐藏其他曲线。

项目保存几何、模型、方案和曲线请求，不保存求解采样或网格。重新打开后需要再次求解，曲线配置会恢复。

## 原生模型与力元

`native-forces.mxmotion` 包含两个自生成长方体、一个旋转副、恒速驱动，以及通过实际参数界面创建的止挡、只拉绳索和体点弹簧。几何尺寸分别为 30 × 10 × 8 mm 和 12 × 16 × 8 mm，均由[原生桌面回归](../tests/MotionOccNativeDesktopSmoke.cpp)直接生成，不依赖外部 CAD 或其他文件。

转子使用运动体 ID 0，固定基座使用 ID 37；原几何 ID 与项目中的部件 ID 不相同，项目已保存实际绑定。求解使用真实 MotionEngine 核心，初始重力为零，转子绕原点处的 Z 轴旋转。

### 操作

1. 打开 `native-forces.mxmotion`。两个部件和原生模型定义会一起载入。
2. 在模型树中右击“原始方案 0”，选择“求解”。
3. 求解完成后，点击方案下的“运动曲线”。四条已保存曲线分别显示驱动位移、只拉绳索幅值、止挡作用状态和体点弹簧变形量。
4. 点击“动画”，播放、暂停或拖动时间轴。停止回到第一帧；关闭动画或切回参数页时恢复初始 CAD 位置。
5. 双击树中的“桌面止挡”“桌面只拉绳索”或“桌面体点弹簧”，查看实际参数。作用点使用初始全局坐标，单位为 mm；参数较多时可在参数列内滚动。
6. 修改参数后重新求解。使用“保存”保留项目，使用“导出运动 JSON”保存原生定义和当前曲线请求；独立 JSON 需要配套几何，`.mxmotion` 已包含几何。

### 应看到什么

| 设置或结果 | 值 |
| --- | --- |
| 转子质量 / 固定基座质量 | 2 kg / 4 kg |
| 恒定角速度 | 90 °/s |
| 结束时间 / 步长 | 1 s / 0.01 s |
| 实际采样 | 101 帧，包含 0 s 和 1 s |
| “原始驱动 9 · 驱动位移” | 从 0° 线性增长到 90° |
| “桌面止挡 · 作用状态” | 初始为 1；0.40 s 时仍为 1，0.41 s 的采样起为 0 |
| “桌面只拉绳索 · 幅值” | 约 0.081 N，本例始终张紧 |
| “桌面体点弹簧 · 变形量” | 约 1.118742 mm |

绳索和体点弹簧的固定端位于 Z 轴上，运动端绕同一轴转动，所以端点距离保持不变，这两条曲线应接近常值。止挡使用沿全局 X 方向的单侧限制，随着转子旋转退出作用范围。四条曲线的单位和量级不同；查看较小数值时，可在曲线列表中暂时隐藏驱动角度曲线，也可导出可见曲线 CSV 核对采样。

该项目保存了上述四条曲线请求，不保存求解结果。每次重新打开后都需要再次求解。
